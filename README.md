# CA Business Platform

A production-style Chartered Accountant business website built with a decoupled architecture.

## Tech Stack

### Frontend

- React
- Vite
- React Router
- Axios
- Bootstrap

### Backend

- Node.js
- Express
- PostgreSQL
- Nodemailer

## Architecture

```
React
   │
REST API
   │
Express
   │
PostgreSQL
```

## Project Structure

```
frontend/
backend/
docs/
```
